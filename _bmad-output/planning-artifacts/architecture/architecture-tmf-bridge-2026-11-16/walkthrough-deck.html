One engine, config as data

TMF-Bridge serves TM Forum Open APIs from configuration. Partners call TMF. Analysts author the translation in a studio. No code, no restart. S1 proves it for reads on a mock backend.

Paradigm

Interpreter runtime, hexagonal. One generic evaluator runs mapping documents stored in the database.

Deployable

One Spring Boot app, two planes: data (serve calls) and control (studio API, drafts, import/export).

Builders

Humans and AI agents. So every rule names its check: ArchUnit, a contract test, a grep test.

Use ← → to move. Open the cards, they hold the decisions.

The system

Three images, one database, one origin at the ingress.

AD-4 Three images, studio is a pure clientStudio calls only the public config API. A test asserts every studio request exists in the springdoc OpenAPI. Runtime-only deployment is the API with control off and no studio image.
AD-3 Plane splitControl beans live under profile control. Runtime code never imports control code. Only control instances migrate the schema. Data pods wait on readiness, they do not crash-loop.

Layers and the dependency rule

AD-2

Domain imports no Spring, JPA or adapter. The only third-party type allowed is Jackson JsonNode. Checked by one ArchUnit suite.

AD-5

Studio tests and production run the same domain CallPipeline. Lineage and step results are observers, on only in studio tests.

The mapping document

JSON, canonical, validated by a published schema. A closed expression tree, no scripting.

{ "schemaVersion": 1,
  "request":  [ { "target": "/path/code", "expr": { "op": "idMap", "resource": "productOrder", "arg": {"path": "/path/id"} } } ],
  "response": [ { "target": "/name",
                  "expr": { "op": "concat", "args": [ {"path": "/body/code"}, {"lit": " - "}, {"path": "/body/label"} ] } },
                { "target": "/productOfferingPrice",
                  "expr": { "op": "map", "over": {"path": "/body/prices"},
                            "as": [ { "target": "/amount", "expr": {"path": "/amount"} } ] } } ] }

State and versions

EntityRule
ApiSpecImmutable, content-hashed. TMF620 and TMF622 v4 seeded, the DB wins afterwards.
MappingOne per operation. Live pointer, at most one Draft. ETag = lock revision.
MappingVersionDraft mutable. Applied immutable (DB trigger). Apply deletes nothing.
BackendReferenced by name, read per call. Delete blocked with 409 while used.
IdMapEntryUnique on (resource, tmfId) and (resource, backendId). Read per call, no cache.

Cache without invalidation

The live pointer is read per call. Compiled mappings are cached by immutable (mapping, number), specs by hash. It cannot go stale.

JPA rules

Lazy associations, explicit JPQL fetch, no entity graphs, entities never cross a port, UTC in the DB, Flyway owns the schema.

Studio, test mode, exports

Test is guarded

Real test calls run in test mode: the backend client allows GET only and refuses before the network.

Preview is stateless

No write port, no draft repository. Samples never reach logs, DB or mapping documents.

One serializer

Exports, bundles and hashes go through the canonicalizer. No generated ids. Export → import → export is byte-identical.

Import

Validate the whole file, then one transaction. Everything lands as Draft. Over an existing Draft the user chooses replace or skip.

Share bundle: one zip with manifest.json mapping.json sample-request.json sample-response.json exchange.json verdict.json postman.json. Secrets appear as $SECRET_VALUE, samples masked with ***.

Security and secrets

AD-13

One filter chain per plane. Control chain always authenticated (OIDC). Runtime chain authenticated unless tmfbridge.runtime.auth.enabled=false. Test: every control endpoint answers 401 without a token.

AD-10

Backends hold a secret name. Value comes from env TMFBRIDGE_SECRET_<NAME> or a mounted file (file wins). One redactor sees every value. Test greps all outputs.

Delivery and operations

Images

tmf-bridge-api, studio-frontend, tmf-mock. Same image in every environment, configuration differs.

Promotion

Export then import. No rebuild.

Demo

docker compose up: Postgres, API, studio, mock, Keycloak. Working within ten minutes of cloning. TMF622 is unmapped on purpose.

Observability

Micrometer, OTLP and Prometheus. Overhead timer, p95 < 100 ms. Server-Timing header on runtime calls.

CI

ArchUnit, Testcontainers, node contract tests, export round trip, secret-leak grep, Spectral, Playwright + axe-core.

Operator owns

PostgreSQL backup and HA. The whole export is a second restore path.
